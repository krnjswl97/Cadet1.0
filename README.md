# Cadet — GitHub Pages Prototype

## Publish from your phone

1. Create a GitHub repository called `cadet`.
2. Upload **all files and folders** in this project. `index.html` must be in the repository root.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait a minute or two.
7. Open the Pages URL on your phone.

## Install as an app

Open the Pages URL in Chrome on Android → browser menu → **Add to Home screen** (wording can vary).

## Notes

This is a front-end prototype. Authentication, database, payments, real matchmaking, persistent test history and server-side scoring are simulated and should be connected later.
